# 画师串导出

柏宝绘（ST-BaiBai-Image）的辅助插件。把柏宝绘里的**画师串**和**角色图片**导出到本地。

柏宝绘本身没有导出功能，这个插件补上这一块。整个插件只读不写，柏宝绘里的东西不会被动到一根头发。

## 它能做什么

### 画师串导出

读取柏宝绘保存的画师串，整理成这种格式：

```
标题：
画师串：
正面质量词：
负面质量词：
```

全选或只挑几条都行，然后复制进剪贴板，或者下载成 txt 文件。

### 角色图片导出

按柏宝绘原有的角色分组读取图库。

- **逐张下载**：文件名是「角色名1、角色名2、角色名3」，每个角色各自计数。
- **打包 ZIP**：压缩包里按角色分文件夹，文件夹名就是角色名。解压后长这样：

```
char/
  char1.png
  char2.png
user/
  user1.png
```

编号按生成时间排，**1 号就是最早生成的那张**，越新编号越大。

## 它绝不做什么

- 不修改柏宝绘的任何设置，不写入、不删除、不改名。
- 不调用柏宝绘的保存方法。
- 不动柏宝绘的界面，入口只加在自己的位置。
- 不动 `baibaiimg` 目录里的任何文件。
- 读图只调用酒馆的图片列表接口，从不调用删除或上传。

画师串数据在插件内部深拷贝后才处理，柏宝绘那边拿到的仍是它自己的原对象。

## 安装

1. 把整个文件夹放进酒馆的扩展目录：

   ```
   SillyTavern\data\<你的用户名>\extensions\
   ```

2. 刷新酒馆页面（F5）。
3. 在扩展列表里确认「画师串导出」已出现并启用。

也可以把文件夹打包成 zip，用酒馆「扩展 → 从文件安装」。

## 使用

两个入口，点哪个都行：

- 顶部工具栏的扩展菜单（四个方块的图标）里的「画师串导出」。
- 「扩展设置」页面里的「画师串导出」区块 → 打开导出面板。

面板是横向布局，左边列表右边内容，高度固定，不会把页面撑高。上面有两个页签。

### 画师串页

- 标「内置」的是柏宝绘自带的只读画师串。
- 标「当前启用」的是你现在正在用的那一条。
- 勾选左边条目，右边实时显示导出内容。
- 「复制」放进剪贴板，「下载文本」存成 txt。

### 角色图片页

左边按角色分组显示缩略图。

- **点缩略图** → 选中/取消，右边同时显示这张的大图
- **双击缩略图** → 全屏查看大图，点任意处或按 Esc 关闭
- **点角色名旁的勾选框** → 整个角色一次选中
- **「全选」「全不选」** → 控制全部

右边预览区：选一张就显示那张；选了多张时显示最后点过的那张，并标明共选了几张。

选好之后：

- **「逐张下载」** → 一张一张存进浏览器下载目录
- **「打包 ZIP」** → 打成一个压缩包，按角色分文件夹

两种方式都会在右下角弹出一条小进度条，显示 `已完成/总数`。打包中可以点叉取消。完成后进度条变绿，然后自动消失。

## 关于正负面质量词显示「无」

柏宝绘里每条画师串的正面质量词和负面质量词是可选绑定。没绑定的条目导出时写「无」，表示它跟随渠道自己的设置，**不是漏读了**。

如果你希望没绑定时自动填入渠道当前实际生效的词，说一声，我加个开关。

## 文件结构

```
画师串导出/
├── manifest.json       酒馆识别插件的清单
├── index.js            打包好的成品，装进酒馆的就是它
├── build.mjs           打包脚本
└── src/
    ├── index.js        入口：挂按钮
    ├── dialog.js       导出面板界面
    ├── gallery.js      图库读取与 ZIP 打包
    └── baibai.js       读取画师串与格式化
```

改完 `src/` 里的文件，跑一次 `node build.mjs` 重新生成 `index.js`。

注意：打包时所有模块会被拼进同一个作用域，所以模块级常量都加了前缀，避免重名。

## 已知限制

- 画师串数据来自柏宝绘的设置存储 `extensionSettings['baibai_image'].nai.artistPresets`。柏宝绘没有公开读取画师串的接口，这里是按它当前的数据结构只读取值。将来字段名若有变动，调整 `src/baibai.js` 即可。
- 内置画师串是从柏宝绘打包文件里抄的固定值，柏宝绘更新内置库时这里不一定同步。
- 图库按「柏宝绘_」前缀识别文件夹，自动跳过「柏宝绘_画师串」这个预览图目录。
- 逐张下载受浏览器限制，连续大量下载可能被拦截，改文件名也只是猜测式重命名，要整批拿请用 ZIP。
- 逐张下载时点取消，只能拦住后面的图，已经发出的下载停不了，这是浏览器决定的。
- ZIP 用不压缩模式打包。图片本身已是压缩格式，体积差别很小。
- 只能在酒馆里跑，脱离浏览器环境无法使用。
