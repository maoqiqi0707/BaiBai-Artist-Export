# 画师串导出

柏宝绘的辅助插件，把已保存的画师串导出成文本。

## 它做什么

读取柏宝绘里保存的画师串，按下面的格式整理出来：

```
标题：清透二次元
画师串：1.2::artist_misa::,0.9::artist_ara::
正面质量词：masterpiece, no text
负面质量词：worst quality
```

可以全选，也可以只勾选其中几条，然后复制或下载成文本文件。

## 它绝不做什么

- 不修改柏宝绘的任何设置，不写入、不删除、不改名。
- 不调用柏宝绘的保存方法。
- 不动柏宝绘的界面，按钮只加在自己的位置。
- 不动 `baibaiimg` 目录里的任何文件。

读完的数据在插件内部做完深拷贝才处理，柏宝绘那边拿到的仍是它自己的原对象。

## 安装

1. 把整个 `画师串导出` 文件夹放进酒馆的扩展目录：
   `SillyTavern\data\<你的用户名>\extensions\`
2. 刷新酒馆页面。
3. 在扩展列表里确认「画师串导出」已启用。

也可以直接把文件夹打包成 zip，在酒馆「扩展 → 从文件安装」里选它。

## 使用

两个入口，点哪个都行：

- 顶部扩展菜单里的「画师串导出」。
- 扩展设置页里的「画师串导出」区块 → 打开导出面板。

面板里会列出全部画师串：

- 标「内置」的是柏宝绘自带的只读画师串。
- 标「当前启用」的是你现在正在用的那一条。
- 勾选想要的条目，下方会实时预览导出内容。
- 「全选」「全不选」控制选定范围。
- 「复制」放进剪贴板，「下载为文本」存成 txt 文件。

## 关于正负面质量词空白

柏宝绘里每条画师串的正面质量词和负面质量词是可选绑定。没绑定的条目在导出时会写「无」，表示它跟随渠道自己的设置，不是漏读了。

如果你希望没绑定时自动填入渠道当前实际使用的词，告诉我，我加一个开关。

## 文件结构

```
画师串导出/
├── manifest.json   酒馆识别插件的清单
├── index.js        打包后可直接运行的成品
├── build.mjs       打包脚本，node build.mjs 即可
└── src/
    ├── index.js    入口：挂按钮
    ├── dialog.js   导出面板界面
    └── baibai.js   读取柏宝绘数据与格式化
```

改动 `src/` 里的文件后，跑一次 `node build.mjs` 重新生成 `index.js`。

## 已知限制

- 画师串数据来自柏宝绘的设置存储 `extensionSettings['baibai_image'].nai.artistPresets`。柏宝绘没有公开读取画师串的接口，所以这里是按它当前的数据结构只读取值。如果将来柏宝绘改了字段名，可能读不到，届时按新版数据结构调整 `src/baibai.js` 即可。
- 内置画师串是从柏宝绘打包文件里抄的固定值，柏宝绘若更新内置库，这里不一定同步。
- 只能在酒馆里跑，没有浏览器环境时无法使用。
